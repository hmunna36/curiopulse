# CurioPulse long-form

One video a week: a short animated film of 4:00–5:00 that answers one science question people already watch by the million. 1920×1080, built in
code like the Shorts, released on Sunday at 17:30 IST. Made by the `/cp-long` skill
([`.claude/skills/cp-long`](../.claude/skills/cp-long)), which a Claude cloud routine runs once a week.

The finished MP4s are not kept in git (they are on YouTube; `src/build.sh` in each folder rebuilds one).
