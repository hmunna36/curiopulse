# CurioPulse long-form topic queue

`/cp-long next` takes the first `[ ]` topic from the top of the queue. An interrupted `[~]` topic is always resumed
first. Edit this file freely: reorder, add, remove, or change an angle. One line per video:

    - [ ] <Question> — <angle: the hiker's situation; act 1 / act 2 / act 3>      queued
    - [~] <Question> — <slug> — started <date>                                     in progress (the next run resumes it)
    - [x] <Question> — <slug> — <link, release day>                                done

Every topic needs three acts (mechanism, proof or twist, the weirdest or still-unexplained thing) AND a small human
story for the hiker: what he wants, and how the answer changes him (reference/long-form.md, "The film bar"). Check
the claims in real sources before writing: the angles below are leads, not facts.
